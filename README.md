# 🚀 **VittaMed: API para Clínica Médica** 🚀

Estou empolgado em compartilhar a conclusão do **VittaMed**, uma API completa para gestão de clínicas médicas! Este projeto abrange cadastros de pacientes, médicos e consultas, e foi desenvolvido utilizando as melhores práticas de segurança e escalabilidade.

---

## 🛠️ **Funcionalidades Implementadas:**

- **Cadastro de Pacientes, Médicos e Consultas**: Gerencie todos os dados essenciais para uma clínica médica com facilidade.
- **Autenticação Segura com JWT (JSON Web Tokens)**: Garantia de segurança para os usuários e seus dados durante o processo de login e autenticação 🔒.
- **Criação de Superusuário**: Para gerenciamento completo do sistema, incluindo usuários, pacientes, médicos e consultas.
- **Integração com PostgreSQL**: Banco de dados robusto e seguro para o gerenciamento das informações da clínica 🗄️.
- **Dockerfile e Docker Compose**: Facilita o deploy da aplicação, garantindo que ela seja escalável e fácil de gerenciar 🐳.
- **Validação de Dados com Regex Validators**: Assegura a precisão das informações inseridas, como CPF, email e outros dados sensíveis.

---

## 💡 **Tecnologias Utilizadas:**

- **Python** | **Django**: Framework backend para desenvolvimento de APIs RESTful 🖥️
- **Django REST Framework**: Para construir e gerenciar as APIs 🛠️
- **PostgreSQL**: Banco de dados relacional para armazenamento seguro e eficiente dos dados 🗄️
- **Docker**: Facilita o gerenciamento e escalabilidade da aplicação 🐳
- **Regex**: Para validação precisa dos dados inseridos 🔍

---

## ⚡ **Como Funciona o Sistema?**

- **Django** gerencia toda a aplicação backend e cria as rotas necessárias para o cadastro e autenticação de usuários.
- **JWT (JSON Web Tokens)** é usado para autenticar usuários e garantir a segurança da comunicação entre cliente e servidor 🔐.
- **PostgreSQL** armazena de maneira robusta todas as informações dos pacientes, médicos e consultas.
- **Docker** facilita a criação de um ambiente de desenvolvimento isolado e a realização de deploy da aplicação.

---

## 🚀 **Destaques do Projeto:**

- **Segurança com JWT**: Autenticação segura e proteção das informações dos pacientes e médicos.
- **Escalabilidade com Docker**: Facilidade no deploy e escalabilidade da aplicação, sem problemas de ambiente 🐳.
- **Validação de Dados**: Uso de Regex para garantir que as informações dos usuários sejam precisas e seguras ✅.
